# Academic profile marks

| File | Artwork source |
|---|---|
| scholar.png | The supplied personal website, images/googlescholar.png. The production PNG retains the supplied artwork and decoded pixels. |
| orcid.svg | The supplied personal website, images/orcid.svg. The original ORCID iD artwork is retained byte for byte. |
| github.svg | Original sidebar icon-github (U+EAE0), from fonts/icomoon/icomoon.svg in the supplied website. |
| linkedin.svg | Original sidebar icon-linkedin2 (U+EAF9), from the same SVG font. |

The GitHub and LinkedIn outlines are by IcoMoon Free (Keyamoon). Their glyph paths were placed in standalone SVGs with a coordinate transform from font units to screen units and a solid platform color. See [IcoMoon Free](https://github.com/Keyamoon/IcoMoon-Free), the [original license statement](https://github.com/Keyamoon/IcoMoon-Free/blob/master/License.txt) and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The marks identify their respective third-party services. Platform trademarks and the supplied Scholar and ORCID artwork remain subject to their owners’ usage terms.

The Social Lab sidebar mark uses the official PNG supplied by Social Lab. The web copy `social-lab-logo-icon.png` trims transparent margins, retaining 13 pixels of clear space and the original artwork pixels. Use as the Social Lab identity.

The active five academic profile icons use the font classes from the original site's js/sidebar.js. Google Scholar, ORCID and the book glyph for the downloadable CV use Font Awesome Free 6.5.0. GitHub and LinkedIn use the original IcoMoon WOFF. All three fonts are served locally from fonts/academic-icons/. The Font Awesome license is included there. The official Social Lab PNG appears in the primary navigation.

The Contact profile row also uses the supplied Scopus SC mark from `images/scopus.png` and ResearchGate RG mark from `images/researchgate.svg`. These are original website assets. The images retain their original artwork and colors; only the resting-state CSS filter and opacity are applied.
